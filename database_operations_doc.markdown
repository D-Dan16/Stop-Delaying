# פעולות על/עם בסיס הנתונים

להלן רשימת המחלקות והפעולות המתקשרות עם מסד הנתונים (Firebase Realtime Database) באפליקציית "Procrastination":

#### 1. UsersRepository
מחלקה זו מנהלת את כל הפעולות הקשורות למידע על המשתמשים, רצפי הצלחות (Streaks) ונתוני לוח המובילים.

*   **fetchUserById**: מושכת נתונים של משתמש ספציפי לפי ה-ID הייחודי שלו מהמסד.
*   **fetchUsers**: מושכת את כל רשימת המשתמשים מהמסד לצורך הצגתם בלוח המובילים (Leaderboard), כולל אפשרות להאזנה לשינויים בזמן אמת.
*   **updateUserDayStreak**: מעדכנת את מספר הימים הרצופים (Day Streak) שבהם המשתמש היה פעיל.
*   **updateUserTaskStreak**: מעדכנת את מספר המשימות הרצופות (Task Streak) שהמשתמש השלים.
*   **incrementUserTaskStreak**: מעלה את רצף המשימות של המשתמש ב-1. הפעולה מתבצעת באופן אטומי מול השרת כדי למנוע בעיות סנכרון.
*   **updateUserHasCompletedTodayATask**: מעדכנת בבסיס הנתונים האם המשתמש כבר השלים משימה אחת לפחות ביום הנוכחי.
*   **incrementUserTaskStreakBy**: מעלה את רצף המשימות של המשתמש בכמות מסוימת שנשלחת כפרמטר.
*   **removeUsersListener**: מסירה את המאזין בזמן אמת מנתוני המשתמשים כדי לחסוך במשאבים ולמנוע דליפות זיכרון.

#### 2. TaskRepository
מחלקה זו אחראית על ניהול כל נתוני המשימות האישיות של המשתמש מול Firebase.

*   **observeUserTasks**: מגדירה מאזין בזמן אמת (Real-time Listener) לכל המשימות של המשתמש המחובר. המשימות נשלפות וממוינות אוטומטית לפי הסטטוס שלהן (לביצוע, בתהליך, הושלם).
*   **addTaskToFirebase**: שומרת משימה חדשה שיצר המשתמש בנתיב המשימות האישי שלו במסד הנתונים.
*   **removeTaskFromFirebase**: מוחקת משימה ספציפית מרשימת המשימות של המשתמש במסד.
*   **updateTaskInFirebase**: מעדכנת פרטים של משימה קיימת (כגון שינוי סטטוס, שם המשימה או תאריך היעד).
*   **removeUserTasksFromFirebase**: מוחקת את כל המשימות המשויכות למשתמש מסוים מהמסד (לדוגמה, בעת מחיקת חשבון).
*   **removeTasksListener**: מפסיקה את ההאזנה לשינויים במשימות המשתמש.

#### 3. Register (פעולת הרישום)
בשלב יצירת המשתמש החדש באפליקציה, מתבצעת אינטראקציה ראשונית עם מסד הנתונים:

*   **createUserAndNextActivity**: לאחר יצירת החשבון ב-Firebase Authentication, האפליקציה יוצרת רשומה חדשה עבור המשתמש תחת הענף `users`. היא מאתחלת את שם המשתמש ואת כל הרצפים (Streaks) ל-0.

#### 4. Login (פעולת ההתחברות)
*   **executeSignIn**: לאחר אימות פרטי המשתמש, האפליקציה מבצעת שליפה (Fetch) של נתוני המשתמש מהמסד כדי לטעון את הפרופיל האישי שלו ולהכין את סביבת העבודה באפליקציה.
