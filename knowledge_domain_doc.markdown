# תיאור תחום הידע

באפליקציית "Procrastination", תחום הידע עוסק בניהול זמן, תעדוף משימות והגברת הפרודוקטיביות באמצעות מערכת מבוססת יעדים ורצפי הצלחות (Streaks).

#### אובייקטים נחוצים
האפליקציה מתבססת על שני אובייקטים מרכזיים המייצגים את הישויות במערכת:
*   **User** (משתמש) - מייצג את הישות האנושית במערכת, הכוללת את זהותו האישית ואת הישגיו.
*   **Task** (משימה) - מייצג יחידת עבודה מוגדרת בזמן שהמשתמש צריך לבצע.

#### סוגי נתונים
להלן פירוט סוגי הנתונים עבור כל אובייקט בטבלאות המפרידות בין שם השדה, הטיפוס והתיאור:

**אובייקט User (משתמש):**

| שם השדה | טיפוס הנתון | תיאור |
| :--- | :--- | :--- |
| userName | String | שם המשתמש |
| dayStreak | int | מספר הימים הרצופים של פעילות |
| taskStreak | int | מספר המשימות הרצופות שהושלמו בזמן |
| hasCompletedTodayATask | boolean | האם הושלמה משימה יומית היום |

**אובייקט Task (משימה):**

| שם השדה | טיפוס הנתון | תיאור |
| :--- | :--- | :--- |
| taskId | String | מזהה ייחודי (UUID) |
| title | String | כותרת המשימה |
| description | String | תיאור המשימה |
| dueDate | Date | תאריך היעד |
| dueTimeOfDay | TimeOfDay | שעת היעד |
| status | Enum | מצב המשימה (לביצוע, הושלם, בוטל) |
| isTaskNotifying | boolean | האם מופעלת התראה למשימה |

#### ייצוג מידע ומבני נתונים
המידע באפליקציה מיוצג ומאורגן במבנים הבאים:
*   **רשימות דינמיות (List / ArrayList):** המשימות מוחזקות בזכרון בתוך רשימות לצורך הצגה ב-RecyclerView. השימוש ברשימה דינמית נבחר כיוון שמספר המשימות משתנה כל הזמן ונדרשת גמישות בגודל.
*   **מיפוי קטגורי (Map / HashMap):** בתוך ה-Repository, המשימות ממוינות לתוך `Map` שבו המפתח הוא הסטטוס והערך הוא רשימת המשימות. מבנה זה מאפשר גישה מהירה ויעילה למשימות לפי הקבוצה אליהן הן שייכות.
*   **עץ היררכי (JSON ב-Firebase):** בבסיס הנתונים, המידע מיוצג כעץ. כל משתמש הוא "ענף" תחתיו נמצאים נתוני הפרופיל שלו וענף נפרד למשימות שלו. זהו ייצוג יעיל לשליפת מידע ספציפי למשתמש ללא צורך בסריקת כל המערכת.

#### CRUD - עדכון, קריאה, הוספה ומחיקה
במהלך השימוש באפליקציה מתבצעות כל פעולות ה-CRUD על נתוני המשימות והמשתמש:
*   **הוספה (Create):** יצירת משימה חדשה או רישום משתמש חדש. נחוץ כדי להתחיל את תהליך ניהול הזמן.
*   **קריאה (Read):** שליפת המשימות להצגה במסך הבית או שליפת נתוני לוח המובילים. זהו הבסיס להצגת מידע למשתמש.
*   **עדכון (Update):** שינוי סטטוס משימה ל"הושלם" או עדכון ה-Streak של המשתמש. פעולה זו חיונית למעקב אחר התקדמות בזמן אמת.
*   **מחיקה (Delete):** הסרת משימה מהרשימה או מחיקת חשבון. מאפשר למשתמש לנהל את המרחב שלו ולהסיר מידע לא רלוונטי.
